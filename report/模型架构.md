# 频域双路检测器：模型架构

面向工业表面缺陷的单阶段检测器。基座为 YOLOv8 式流水线（已与 ultralytics 逐位
对拍验证），改动为**并联一条频谱支路，并以类别条件门控与空域特征融合**。

---

## 1. 总体结构

```
                ┌── CSPDarknet 主干 ──────► C2  C3  C4  C5
                │                            (4) (8) (16)(32)
输入 640×640 ───┤                                  │   │
                │                                  ▼   ▼
                └── 频谱支路 ────────────────────► (⊕) (⊕)     ← 仅在 P4/P5 融合
                     分块 FFT → 径向×方向带池化      ▲   ▲
                     → 轻量卷积栈                    │   │
                                                    └─┬─┘
                                       门控 g = f(图像级分类)
                                  F = (1−g)·F_空域 + g·F_频域
                                              │
                                              ▼
                                  PANet neck (C2–C5)
                                              │
                                              ▼
                          解耦检测头：分类分支 + DFL 定位分支
                          TAL 动态标签分配 · CIoU + DFL 损失
                                              │
                                              ▼
                                    NMS (IoU 0.45) → 检测框
```

**参数量**：主干 4.42M + 频谱支路 0.41M = **4.83M**，约 42 GFLOPs。
多尺度版（patch 8/16/32）为 5.50M / 55 GFLOPs。

---

## 2. 频谱支路

### 2.1 分块 FFT 与带池化

```
灰度图 (B,1,H,W)
  └─ unfold 成 p×p 不重叠块          → (B·L, p, p)，L = (H/p)·(W/p)
  └─ [可选] Hann 窗逐点相乘
  └─ rfft2 → |·| → log1p            → (B·L, p·(p/2+1))
  └─ 带矩阵 M (F × K) 线性投影        → (B·L, K)，K = n_radial × n_orient
  └─ reshape + BatchNorm             → (B, K, H/p, W/p)
  └─ 两层 3×3 Conv → width           → stride p
  └─ 3×3 Conv stride 2 → 2·width     → stride 2p
```

带矩阵 `M` **无参数**，由频率平面的径向/方向分箱构成：对 rfft2 输出的每个频点
计算 `r = √(f_y²+f_x²)` 与 `θ = atan2(f_y,f_x) mod π`，按 `n_radial × n_orient`
分箱后取箱内均值。默认 `n_radial=8, n_orient=4`，即 32 维纹理描述子。

**默认 `patch=16`**，故支路输出恰好落在 stride 16 与 32，即 P4 与 P5。

### 2.2 设计依据（均为实测，见实验报告 §5.3）

| 设计 | 依据 |
| --- | --- |
| 使用频域而非更多卷积 | 图像原始分辨率仅 200×200，像素域信息量已饱和；容量从 2.5M 到 31M 的六种配置 mAP 全部落在 0.72–0.74 |
| **方向分箱** | 全数据集共享轧制方向；实测 scratches 在轴对齐方向的带能量（+0.64/+0.55）为斜向（+0.35/+0.35）的 1.6–1.8 倍 |
| **仅在 P4/P5 融合** | 弥散类别的框为 216–489 px，只可能落在粗层级；而边界清晰的类别位于 P2/P3，历次大感受野改动均损害该组 |
| 径向分箱 | 各类的判别能量随频率单调衰减（r0 段 +0.03~+0.64，r3 段 +0.01~+0.04） |

## 3. 类别条件门控

```
P5 特征 ──► 全局平均池化 ──► 全连接 ──► 图像级分类 logits (B, nc)
                                              │
                          softmax · sigmoid(每类可学习亲和度)
                                              │
                                     g ∈ (0,1)，形状 (B,1,1,1)
```

融合规则：`F_k = (1 − g)·F_空域,k + g·Proj(F_频域)`，其中 `Proj` 为 1×1 卷积，
将频谱通道数对齐到该层级的主干通道数。

**依据**：NEU-DET 中 **93.2% 的图像只含一个缺陷类别**（1800 张中仅 123 张多类别），
因此图像级分类器在此近乎神谕，门控信号可靠——这与一般混合专家中需要靠训练摸索
路由的情形不同。

每类亲和度为**可学习标量**而非人工设定：我们知道纹理支路对不同类别的重要性不同，
但不知道具体比例，写死等于在验证集上调参。

### 辅助监督

门控的分类头同时接受**多标签图像级监督**（`aux_cls_weight` 默认 0.2），
处理那 6.8% 的多类别图像。若无此监督，门控仅由检测损失塑形，易塌缩为常数。

---

## 4. 检测头（与基座一致，未改动）

- **两条分支**：分类（nc 通道）与定位（4×reg_max，DFL 分布式回归）。
- **无 objectness 分支**：TAL 的分类目标本身即为 IoU 加权，再乘一个 IoU 形状的
  置信度等于折扣两次，代价主要由大目标承担（检出但在排序中被压下）。实测删除该
  分支在本数据集上带来 mAP50 +0.009，其中 pitted_surface +0.15。
  代码中以 `--use-obj` 保留用于消融。
- **分类分支 bias 按层级初始化**：`log(5 / nc / (imgsz/stride)²)`。统一常数会让
  stride 8（6400 个 anchor）承受 stride 32（400 个）16 倍的负样本 BCE 质量。
- **reg_max = 16**：单边最远 15 格，故 stride 32 可表示 960 px 的框，覆盖数据集中
  最大的 621 px 目标。

## 5. 关键实现约束

### 5.1 标签分配必须在 fp32 下进行

```python
t_labels, t_bboxes, t_scores, fg = self.assigner(
    pred_scores.float(),
    (pred_bboxes.detach() * strides).float(),   # 必须
    anchors.float(), gt_labels.float(), gt_bboxes.float(), mask_gt, ...)
```

在 autocast 下预测框为 fp16，而 CIoU 需计算外接框对角线平方；640 像素坐标下
边长超过 **181 px** 时 `c² > 65504`（fp16 上限），惩罚项溢出为 inf/nan，
对齐度量无法通过 `>0` 判定，该目标在所有层级上都拿不到正样本。

本数据集中 rolled-in_scale（216 px）、crazing（289 px）、pitted_surface（489 px）
三类的典型框尺寸均超过该阈值，故此项为必需而非可选。

### 5.2 评估协议

| 项 | 取值 | 说明 |
| --- | --- | --- |
| conf | 0.001 | AP 计算需要完整 PR 曲线 |
| NMS IoU | **0.45** | COCO 默认 0.7 在本数据集上偏松；三个独立模型均在 0.45 取最优，增益 +0.013~+0.036 |
| multi_label | True | 与参考实现一致 |
| AP | COCO 101 点插值 | — |
| 命中分配 | 按置信度 | 真值被多框命中时记给置信度最高者（COCO 约定） |

### 5.3 训练配方

| 项 | 取值 | 依据 |
| --- | --- | --- |
| 优化器 | AdamW，lr 1e-3，wd 5e-4 | — |
| 调度 | 余弦，lrf 0.01，warmup 3 轮 | — |
| 轮数 | 150 | — |
| batch | 16 | — |
| **mosaic** | **关闭** | 在本数据集上实测为净负（−0.10）；两种实现方式（裁剪重采样 / 单次仿射）均如此 |
| 增强 | 水平翻转 0.5、垂直翻转 0.3、90° 旋转 0.3、亮度 0.3、逐图仿射（scale 0.5 / translate 0.1） | 关闭翻转与旋转使 scratches 从 0.630 降至 0.446 |
| `min_box_visibility` | 0.1 | 与参考实现的 `area_thr` 一致；更严的阈值会系统性淘汰高频受裁剪的大框 |
| EMA | 全模型，decay 0.999 | — |

## 6. 消融与被否决的设计

### 已验证有效

| 组件 | 增益 | 显著性 |
| --- | --- | --- |
| 频谱支路 + 类别门控 | +0.0166 | t=3.96，p<0.05 |

### 已实现但实测无效（保留开关供消融表使用）

| 组件 | 参数 | 结果 |
| --- | --- | --- |
| 多尺度频谱 8/16/32 | `--freq-patch 8,16,32` | +0.0005，t=0.11 |
| Hann 窗 | `--hann` | +0.0009，t=0.18 |
| 相位特征（带内圆周均值） | `--phase` | mAP50-95 0.3680 < 底座 0.3745，未达设计目的 |
| 对数径向分箱 | `--log-radial` | 单种子 0.7525，噪声内 |
| 空间门控 | `--gate-mode spatial` | 未单独验证 |
| 辅助分割监督 | `--aux-seg-weight` | 单种子 0.7499，噪声内 |
| objectness 分支 | `--use-obj` | 有害，见 §4 |

### 依据不足未实现

**按频带路由**（每个频带一个注意力权重）：前提是各类占据不同频带。实测五个
正号类别之间的频带形状余弦相似度为 0.85–0.97，差异在幅度而非分布，
故未实现。（patches 因符号为负而与其余类相似度为负，会把平均值拉低至 0.32，
不可据此判断可分性。）

### 消融的局限

去掉傅里叶变换（保持路径结构与参数量不变）后为 0.7380 ± 0.0089，
介于基线 0.7317 与完整模型 0.7482 之间，**与两侧均不显著**（t=1.18 与 1.60）。
按当前效应量与方差估算需每组约 10 个种子方能分辨。
**因此"增益来自频域信息"这一论断尚未被证实**，论文中应如实说明。

## 7. 与既有工作的关系

本结构的各组件均有前作，**不应作为原创性主张**：

| 组件 | 相关方法族 |
| --- | --- |
| CNN 中的频域分支 | FFC、GFNet、FcaNet、小波类（MWCNN/WaveCNet）；空域+频域双流在图像取证中成熟 |
| 径向×方向带池化 | 经典纹理分析的 ring/wedge 滤波，Gabor / log-Gabor 描述子 |
| 分支间门控 | 混合专家、条件计算、SE 式门控 |
| 辅助图像级分类损失 | 标准多任务 |

**可主张的是设计依据而非模块本身**：三处关键选择（方向分箱、仅融合 P4/P5、
类别条件门控）分别由本数据集的三个实测性质导出——共享轧制方向、弥散类别的
框尺寸只能落在粗层级、93.2% 单类别结构。这些性质在一般自然图像上不成立，
故同一模块迁移到其他数据未必有效。
