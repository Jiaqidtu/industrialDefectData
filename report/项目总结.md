# 项目总结：工业表面缺陷检测的可测性极限

NEU-DET / GC10-DET · 2026-09-05

数据处理与模型结构见 [模型架构.md](模型架构.md)。本文档记录实验结果、统计检验与结论。

---

## 摘要

本项目从零实现了一个 YOLOv8 风格的表面缺陷检测器，并在 NEU-DET 与 GC10-DET 上建立了带独立测试集、多种子、统计检验的评估协议。

**三个主要结论：**

1. 我们的 8.9M 模型在独立测试集上达到 **mAP50 = 0.7216 ± 0.0142**，显著优于 32M 的 RT-DETR-l（0.6645 ± 0.0225，t = 3.72）。
2. 同一批权重从验证集到测试集，mAP50 系统性下降 **0.013 – 0.033**。该幅度**超过**文献中大多数方法声称的改进量。
3. 在此数据规模下，我们测得的**最小可检出效应**为全局 mAP50 约 **0.028**；小样本类别（如 crazing，110 个测试框）需要约 **0.10**。我们尝试的九项架构改动全部落在该阈值以下。

---

## 一、评估协议

### 1.1 三分划分

70 / 15 / 15，按主类别分层，seed 0。NEU-DET 1260 / 270 / 270，GC10-DET 1596 / 344 / 340。

**测试集在训练与模型选择的全过程中不被触碰。** 最优 epoch 依据验证集选择，测试集只在最终评分时使用一次。

### 1.2 统计判据

- 每个配置跑多个随机种子（主表 n = 3，消融 n = 7）
- 组间比较用 **Welch t 检验**（不假设方差齐性）
- n = 3 时 df ≈ 3，α = 0.05 双侧临界值 **|t| > 3.18**
- n = 7 时 df ≈ 12，临界值 **|t| > 2.18**
- 逐类比较（6 个类别）需 Bonferroni 校正，n=3 时阈值为 **|t| > 4.86**

### 1.3 判据必须在实验之前登记

本项目中有**六次**单种子结果在补充种子后消失。每一次在当时看都完全可信：

| 声称的效应 | 单种子 Δ | 补种子后 |
|---|---|---|
| ADMSB 主干改善 crazing | +0.07 | 消失 |
| SAM2 改善 rolled-in | +0.05 | 消失 |
| 去除 FFT 的消融 | +0.04 | 消失 |
| Hann 窗 | +0.03 | 消失 |
| 多尺度 patch | +0.03 | 消失 |
| **MPS 张量网络改善 crazing** | **+0.072** | **消失（见 §5.2）** |

因此 [`mps_test.sh`](../mps_test.sh) 被设计为：**两组种子未满即拒绝输出结果**，判据写死在脚本中。中途查看并在好种子处停手，与 p-hacking 在统计上无法区分。

## 二、基线恢复

项目初期我们自己的实现得到 mAP50 = 0.3585，而参照的 ultralytics YOLOv8n 在同一数据上得到 0.7124。通过与参照实现逐模块二分比对，定位到四个 bug：

| 问题 | 影响 |
|---|---|
| **混合精度下 CIoU 溢出** — 框边长 > 181 px 时外接框对角线平方超过 fp16 上限，所有大框得不到正样本 | **+0.146** |
| **TP 分配按 IoU 而非置信度** — 每个 GT 保留 IoU 最高而非置信度最高的检测 | **+0.06** |
| EMA 只平均 neck + head，未包含主干 | 中等 |
| NMS IoU 阈值未标定 | 小 |

最终恢复到 0.7317，与参照实现相当。诊断过程中新增的**逐层级正样本计数**（`pos/8`、`pos/16`、`pos/32`）是发现第一个 bug 的关键——日志中 `pos/32: 0.0` 直接指出 P5 层从未被激活。

> 这一节的意义在于：**一个看起来在正常训练、损失正常下降的检测器，可能有一半的性能被数值细节吃掉。** 没有参照实现做逐模块比对，这类问题几乎不可能定位。

### 3.1 NEU-DET 独立测试集（640 px，3 种子）

| 模型 | 参数 | test mAP50 | test mAP50-95 |
|---|---|---|---|
| **本文 freqdual** | **8.9 M** | **0.7216 ± 0.0142** | 0.3887 ± 0.0120 |
| 本文 SAM2/Hiera | 31 M | 0.7250 ± 0.0084 | 0.3746 ± 0.0086 |
| 本文 freq + Hiera | 31 M | 0.7179 ± 0.0022 | 0.3739 ± 0.0037 |
| 本文 纯 CNN | 8.9 M | 0.7168 ± 0.0113 | 0.3753 ± 0.0071 |
| YOLOv8n | 3.2 M | 0.7068 ± 0.0177 | 0.3837 ± 0.0161 |
| YOLOv8s | 11 M | 0.6958 ± 0.0048 | 0.3764 ± 0.0068 |
| **RT-DETR-l** | **32 M** | **0.6645 ± 0.0225** | 0.3675 ± 0.0103 |

**显著性检验**（freqdual 对各基线）：

| 对比 | Δ | t | 显著（\|t\| > 3.18） |
|---|---|---|---|
| vs RT-DETR-l | +0.0571 | **+3.72** | **是** |
| vs YOLOv8s | +0.0258 | +2.99 | 否 |
| vs YOLOv8n | +0.0148 | +1.13 | 否 |
| vs 纯 CNN | +0.0048 | +0.46 | 否 |

**唯一显著的正面结论**：我们的模型以 8.9 M 参数显著优于 32 M 的 RT-DETR-l。需要说明的是，我们的纯 CNN 基线同样优于 RT-DETR——**优势来自整体训练配置与检测范式，而非频域分支**。

### 3.2 逐类结果（freqdual, test）

| 类别 | AP50 |
|---|---|
| scratches | 0.9337 ± 0.0126 |
| patches | 0.8888 ± 0.0251 |
| pitted_surface | 0.7529 ± 0.0200 |
| inclusion | 0.7505 ± 0.0150 |
| rolled-in_scale | 0.6110 ± 0.0099 |
| **crazing** | **0.3928 ± 0.0405** |

性能瓶颈集中在 `crazing` 与 `rolled-in_scale` 两个**弥散纹理**类别。§4 分析其成因。

### 3.3 RT-DETR 的数值失稳

RT-DETR-l 在混合精度下于 **epoch 107 崩溃**：训练损失保持正常（giou 0.342 / cls 0.531 / l1 0.279），但**所有验证指标永久归零**。原因是 ultralytics 用 EMA 副本做验证，EMA 一旦吃进一个 NaN 更新便永不恢复。

改为 fp32 训练后，三个种子各 150 epoch **零次崩溃**。本文报告的 RT-DETR 数字均来自 fp32 版本。

> 该现象与我们自己遇到的两个 fp16 问题（CIoU 溢出、跨域注意力 softmax）同源：**训练看起来健康而验证悄悄失效**，是混合精度检测器中一类值得警惕的失效模式。

## 四、瓶颈定位

### 4.1 弥散类别的天花板是标注噪声

**crazing 的实例数不可学。** 我们实现了一个无 NMS 的实例分解头（[`model_newage/instdecomp.py`](../model_newage/instdecomp.py)），预测区域图 + 实例数 K + 槽位分配，作为 crazing 专用模型训练。结果：**计数准确率 0.467，恰好等于多数类基线**。

即模型无法比「永远猜最常见的数字」做得更好。crazing 是连续的密集裂纹网络，将其切分为 2 个还是 5 个框本质上是标注者的任意选择，不存在可学习的信号。

**pitted_surface 退化为分类。** 该类框的中位边长为原图的 73%，最大接近整图。检测退化为「这张图有没有麻点」的二分类，定位几乎不提供信息——这解释了它的 AP50（0.75）与 AP50-95 之间的巨大落差。

### 4.2 验证集选择性的量化

同一批权重、同一个模型，val（最优 epoch）与 test 的差值：

| 模型 | val − test |
|---|---|
| freqdual | **+0.0299 ± 0.0088** |
| 纯 CNN | **+0.0330 ± 0.0048** |
| freq + Hiera | +0.0196 ± 0.0024 |
| SAM2/Hiera | +0.0130 ± 0.0075 |

我们进一步在同一批实验上做过对照：某个改动在验证集上 t = 3.96（"显著提升"），换到独立测试集后 t = 0.46。

**这个 0.013 – 0.033 的幅度，与文献中大多数方法声称的改进量（0.02 – 0.03）处于同一量级。** 在没有独立测试集的协议下，无法区分「方法有效」与「在验证集上选到了好的 epoch」。

### 4.3 输出端已经封闭

我们测试了后处理重组能否挽救弥散类别：加权框融合（WBF，3 个 IoU 阈值）、邻接并集聚类（3 个 tau），以及一个**神谕上界**——每张图从 7 个变体中用真值挑最优。

**NEU-DET（270 张 val）**

| 方法 | mAP50 | crazing |
|---|---|---|
| 基线（不合并） | 0.7467 | 0.3864 |
| WBF iou = 0.5 / 0.7 | 0.7467 | 0.3864 |
| WBF iou = 0.3 | 0.7399 | 0.4078 |
| 邻接并集 tau = 0.01 | 0.3519 | 0.0072 |
| **神谕上界** | **0.7813** | 0.4723 |

**GC10-DET（344 张 val）**

| 方法 | mAP50 | crease |
|---|---|---|
| 基线 | 0.6190 | 0.1194 |
| WBF iou = 0.5 / 0.7 | 0.6190 | 0.1194 |
| 邻接并集 tau = 0.01 | 0.3856 | 0.2488 |
| **神谕上界** | **0.6683** | 0.3821 |

三点观察：

1. **WBF 在 IoU ≥ 0.5 时逐类结果与基线一位不差** —— 模型输出中根本不存在 IoU > 0.5 的同类冗余框对，NMS 已经清理干净，WBF 无物可融。
2. **两个真实算法都是净负的**。邻接并集把本该分开的相邻缺陷并成大框，摧毁了原本正确的中小框。
3. **神谕上界仅高出基线 +0.035（NEU）/ +0.049（GC10）**，而这已是每张图用真值从 7 个变体中挑选的极度乐观估计。

**结论：弥散类别的瓶颈位于候选生成阶段，而非后处理阶段。** 重组已有输出拼不出缺失的部分。

唯一的例外是 GC10 的 `crease`：邻接并集拿到 0.2488（上界 0.3821），是全表唯一一个真实算法达到上界一半以上的类别。该类真值本身就是整条大范围折痕，而模型输出的是碎片。但它是 10 类中的 1 类，全局收益仅 +0.013，单数据集单种子——达不到可发表的证据强度。

### 5.2 MPS 张量网络（重点记录）

预先登记的判据：**crazing \|t\| > 3.18 且全局 mAP50 不下降**。

**n = 3 时**（对照组 s0–s2）：

```
crazing  freqdual: [0.3862, 0.4666, 0.4456]
             +MPS: [0.4754, 0.4987, 0.4713]   三个种子全部高于对照组最大值
```

Δ = +0.049，t = 1.92。效应量 d ≈ 1.57，按 n = 16/d² 需要每组 7 个种子才有 80% 检验力。对照组恰好已有 7 个种子，因此补齐 MPS 组。

**n = 7 时**：

| 指标 | freqdual (n=7) | +MPS (n=7) | Δ | t |
|---|---|---|---|---|
| mAP50 | 0.7586 ± 0.0070 | 0.7581 ± 0.0084 | −0.0004 | −0.11 |
| mAP50-95 | 0.3914 ± 0.0106 | 0.3791 ± 0.0117 | −0.0123 | −2.07 |
| crazing | 0.4362 ± 0.0271 | 0.4644 ± 0.0255 | +0.0281 | 2.00 |
| inclusion | 0.7669 ± 0.0191 | 0.7431 ± 0.0173 | −0.0237 | −2.44 |

crazing 的效应从 +0.049 回落到 +0.028，是典型的向均值回归。逐种子配对：

| seed | freqdual | +MPS | 差 |
|---|---|---|---|
| s0 | 0.7481 | 0.7613 | **+0.0132** |
| s1 | 0.7636 | 0.7673 | +0.0037 |
| s2 | 0.7613 | 0.7588 | −0.0026 |
| s3 | 0.7580 | 0.7570 | −0.0010 |
| s4 | 0.7506 | 0.7531 | +0.0025 |
| s5 | 0.7679 | 0.7665 | −0.0014 |
| s6 | 0.7604 | 0.7429 | **−0.0174** |

**7 次配对中 MPS 赢 3 次**，两组区间几乎完全重叠（0.7481–0.7679 vs 0.7429–0.7673）。最大的两个差值方向相反且量级相当。

**判定：否定结果。** 且 MPS 有明确代价：mAP50-95 −0.012、inclusion −0.024、FPS 从 121 降至 77。

### 5.3 COCO 预训练不迁移

我们逐张量核对确认 `CSPBackbone` 与 ultralytics yolov8s 主干等价，实现了权重映射（125 个张量全部命中）。

结果：**Δ = +0.0042，t = 0.63**。逐类有 ±0.03 – 0.05 的变动（scratches +0.031、inclusion +0.050、crazing −0.046），但方向互相抵消，且无一通过 Bonferroni 校正（阈值 4.86）。

**解释**：钢材表面纹理与自然图像的低层统计差异过大，1260 张图的微调足以洗掉预训练特征。这一结果同时否定了「我们与文献的差距主要来自预训练」这一假设。

## 六、与文献的对照

以 DSAT（DETR + ResNet-18）为例，该文报告 NEU-DET mAP50 = 83.14%、GC10-DET 67.27%。我们在自己的协议下得到 72.16% / 61.90%。

**差距的来源分析：**

| 因素 | 估计贡献 | 依据 |
|---|---|---|
| **协议差异** | ~0.03 | 该文未说明 NEU-DET 划分比例，两个数据集均无独立测试集，无种子方差。我们实测 val − test = 0.030 |
| **划分种子差异** | 0.01 – 0.02 | 1800 张的数据集，换划分种子波动即达此量级 |
| **训练轮数** | 未知 | 该文 250 epochs，我们 150 |
| 预训练 | ~0 | §5.3 已否定 |
| 架构真实增益 | 剩余部分 | 无法评估——该文无种子方差，且未开源 |

**关键佐证**：我们在自己的协议下跑了同族方法 RT-DETR-l，得到 crazing AP50 = 0.270（该文报告 0.668）。**同族方法在两种协议下的差距（0.40）远大于不同方法之间的差距。**

我们没有复现 DSAT 本身——该文未开源，且未给出划分比例、batch size、数据增强与预训练权重来源。在这种信息量下重实现，得到的低分无法归因于方法本身。

**GC10-DET 逐类对照**（DSAT vs 本文）：

| 类别 | DSAT | 本文 | 差 |
|---|---|---|---|
| punching_hole | 92.4 | 97.96 | **+5.6** |
| weld_line | 95.2 | 82.73 | −12.5 |
| crescent_gap | 93.7 | 91.95 | −1.8 |
| water_spot | 80.5 | 76.95 | −3.6 |
| oil_spot | 65.3 | 63.53 | −1.8 |
| silk_spot | 57.4 | 52.02 | −5.4 |
| inclusion | 29.6 | 27.70 | −1.9 |
| rolled_pit | 27.7 | 24.80 | −2.9 |
| **crease** | **38.3** | **11.94** | **−26.4** |
| waist_folding | 84.1 | 89.43 | **+5.3** |
| 总计 | 67.27 | 61.90 | −5.4 |

5.4 个百分点的差距中，`crease` 一类贡献了 2.6 点（近一半）；其余九类平均只差 1.6 点，其中两类我们更高。这不是全面的架构优势差异，而是单一类别的失效。

值得注意：我们的神谕上界为 `crease` 算出的是 **0.382**，DSAT 报告的是 **0.383**——暗示我们的模型已经检测到该缺陷，只是切分方式不同。

## 七、可测性极限

综合全部实验，本数据规模下的最小可检出效应：

| 指标 | 种子标准差 | 最小可检出效应（n=3, 80% 检验力） |
|---|---|---|
| 全局 mAP50 | ~0.010 | **~0.028** |
| crazing AP50（110 个测试框） | ~0.040 | **~0.10** |

这意味着：

- **一篇声称在 NEU-DET 上提升 2% 的论文，若只报单个数字而无方差，其结论无法与随机种子波动区分。**
- 小样本类别上的「类别特异性提升」尤其危险——本项目中有六次这样的效应在补充种子后消失。

## 八、结论

1. **实现层面**：混合精度下的数值失效是检测器中一类隐蔽而严重的问题。CIoU 在 fp16 下的溢出使我们的模型损失了 0.146 mAP，而训练日志表现完全正常；RT-DETR 的 EMA 被单个 NaN 永久污染，训练损失同样正常。逐层级正样本计数是发现这类问题的有效工具。

2. **协议层面**：NEU-DET 规模下，验证集选择性带来的高估（0.013 – 0.033）与文献中通行的改进声称量级相当。**独立测试集与多种子方差应当是该基准上的最低报告要求。**

3. **方法层面**：我们尝试的九项架构改动——频域双域、张量网络、跨域注意力、类别门控、频带路由、多尺度、SAM2 主干、COCO 预训练、后处理重组——在统计上全部为零结果。合并算法的神谕上界（+0.035）表明输出端已经封闭；实例分解头的计数准确率等于多数类基线，表明弥散类别的标注本身不自洽。

4. **性能层面**：本文 8.9 M 的模型在独立测试集上显著优于 32 M 的 RT-DETR-l（+0.057，t = 3.72），但与我们自己的纯 CNN 基线无显著差异——**优势来自训练配置与检测范式，而非所提出的频域分支**。

**总体判断：在 NEU-DET 这一规模上，架构改进的可测空间已经关闭。** 进一步提升需要的是更大规模、标注更自洽的数据，而非新的模块。
